# 专辑墙 Tag 筛选实现计划

> 状态：供审阅的计划草案；本轮不编写实现代码。
> 后续执行：使用 superpowers:executing-plans 按任务实施，并逐项验证。

**Goal:** 在首页顶部混合展示音乐风格、艺术家标签；点击标签变蓝，未匹配专辑淡出，剩余专辑平滑补位。

**Architecture:** 首页继续在服务端读取专辑数据；AlbumGrid 成为管理筛选状态和动画的客户端组件。标签栏只负责展示与交互，筛选规则独立为纯函数；复用现有 Framer Motion。

**Tech Stack:** 项目现有 Next.js 16、React 19、TypeScript、Tailwind CSS 4、Framer Motion 12。

**Spec:** 本文的交互、视觉和动画约定依据本次用户需求编写；单选规则和具体视觉参数为建议默认值，可在实现前调整。

## 需求与范围

- 页面顶部新增统一标签栏，音乐风格与艺术家混排，不分两个区域。
- 被选标签呈蓝色高亮，只有匹配的专辑留在网格内。
- 未匹配专辑通过动画消失；剩余专辑按照原始顺序向前补位。
- 复用现有专辑卡片和详情交互；本次范围为首页筛选。
- 当前生成数据有 24 张专辑、23 个艺术家值、15 个音乐风格值。
- 数据已有 `artist` 和可选的 `genre` 字段，无需增加后台或请求接口。

## 交互约定

1. 初始显示全部专辑，“全部”按钮选中。
2. 初版采用单选：点击一个标签，仅显示其匹配专辑；点击另一标签直接切换。
3. 再次点击当前标签或点击“全部”，恢复全部专辑。
4. 所有标签始终可见，不因筛选结果重新生成、重排或消失，方便切换。
5. 标签按全部数据中的出现频次降序混排，同频按首次出现顺序稳定排列；“全部”固定最前。
6. 筛选不改变专辑原始排序，也不触发页面导航或滚动到顶部。
7. 打开专辑弹层并关闭时保留首页筛选状态；刷新页面恢复全部。本期不增加 URL 参数或持久化。
8. 快速连点时标签立即响应，动画以最新选择为准，避免旧动画回调覆盖新结果。

## 按钮与布局

- 采用 Apple Store 风格的简洁胶囊按钮：大圆角、细边框、轻量留白，不添加厚重阴影。
- 未选中：浅灰底、深灰文字；悬停略加深背景。
- 选中：蓝色实底、白色文字；初始建议蓝色 `#0071e3`，实现时检查文字对比度。
- 字号约 14px，点击区域高度至少 44px，标签间距约 8px。
- 标签栏与专辑网格左右边缘对齐；宽屏自然换行，手机单行横向滚动，露出后续标签作为滚动提示。
- 手机长标签保留完整文字，不按标点拆断；键盘聚焦标签时让其滚入可见区域。
- 标签栏放在正常文档流的顶部，不使用吸顶，避免多行标签持续遮挡专辑。
- 标签使用原生 button、`aria-pressed` 和清晰的键盘焦点样式；结果数量通过简短的 live region 通知辅助技术。

## 数据规则

- 标签由全部专辑的 `artist` 与非空 `genre` 自动生成，移除首尾空白、忽略空值、同类型去重。
- 标签内部使用“类型 + 值”作为唯一标识，防止艺术家和风格重名时串选；只在实际重名时增加简短类型提示。
- 对完整字段值做精确匹配，不使用子串匹配。
- 本期保留原始分类：`R&B`、`R&B / SOUL`、`Soul/R&B` 暂时作为不同标签，不擅自合并。
- 不按逗号、斜杠或 `&` 自动拆分艺术家名字；例如 `Tyler, the Creator` 保持完整。
- 缺少风格的专辑仍然可通过艺术家筛选，并出现在“全部”中。
- 不直接修改 `src/generated/albums.json`，该文件由内容准备流程生成。

## 动画方案

采用“两阶段退场与补位”，保持用户要求的先后关系：

1. 点击后约 120–160ms 内完成按钮颜色过渡。
2. 未匹配专辑在原位置用约 160ms 淡出，并轻微缩小至 0.97；此阶段保留其网格占位。
3. 退场完成后移除占位，剩余卡片用约 280–360ms 平滑移动到新位置。
4. 恢复全部或切换标签时，新出现的卡片轻微淡入；持续存在的卡片只移动，不重复闪烁。

技术上使用 AnimatePresence 管理退场、布局动画管理位置变化；避免直接 `display: none` 造成跳动。为保持先退场后补位，不采用会立即释放占位的 popLayout 作为默认方案。切换时区分“目标结果”与“当前渲染集合”，在退场完成后提交最新集合；动画回调需检查当前目标，避免过期结果回写。

- 动画外层以 `album.slug` 为稳定 key，不以数组下标为 key。
- 布局移动与现有封面 hover 缩放放在不同层级，避免 transform 冲突。
- 使用位置动画，避免封面在网格重排时被拉伸。
- 退场中的卡片禁用点击与键盘进入，避免点击即将消失的专辑。
- 尊重 `prefers-reduced-motion`，减少动态效果时直接更新或仅短暂淡入淡出。
- 重点验证页面变短、滚动条消失时的宽度变化和滚动位置，必要时使用稳定滚动条槽位。

## 验收标准

- 风格与艺术家位于同一条顶部标签区域，选中态明确为蓝色。
- 每次筛选只显示匹配专辑，排序与筛选前一致；取消后完整恢复。
- 未匹配专辑有退场动画，剩余专辑平滑向前补位，不留下空位。
- 快速切换后的最终结果始终与最后选中的标签一致。
- 手机不出现整页横向溢出；标签能够完整阅读和操作。
- 详情弹层关闭后仍保留筛选；键盘和减少动态效果设置下功能可用。

## 重点风险

1. 原始风格名称不统一：本期忠实保留，后续另行整理内容分类。
2. 连续点击覆盖动画回调：以最新目标驱动最终渲染集合并专门验证。
3. hover 缩放与布局动画冲突：使用分层容器处理。
4. 页面高度和滚动条改变造成视觉跳动：在实际长页面滚动位置下检查。
5. 客户端组件影响弹层返回状态：通过现有拦截路由流程回归验证。
